# 00 - 目录与阅读指引

> **引导问题：** 面对一个包含 100+ 源码文件、涵盖 CLI/Agent/Gateway/Tools/Skills 五大子系统的 AI Agent 框架，应该从哪里开始读？按什么顺序读最高效？

## 关于本书

本书是 [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) v0.9.0 版本线的深度源码解析系列，共 **25 篇正文 + 3 篇实战附录**。

### 目标读者

- **1-3 年 Python 经验**的程序员
- 对 AI Agent / LLM 应用开发感兴趣
- 想深入理解一个生产级 Agent 框架的内部实现

### 你将收获

1. **架构理解** — Hermes 的整体设计思想与模块划分
2. **源码阅读能力** — 跟随本书逐文件拆解，培养读大型 Python 项目的能力
3. **设计模式** — 每篇结尾提炼 2-3 个可迁移到自己项目的设计模式
4. **上手开发能力** — 通过 3 篇实战附录，具备为 Hermes 贡献代码的能力

### 阅读约定

- **中文为主**，技术术语保留英文原文（如 Agent、Tool、Context Window）
- **代码引用**精确到文件路径和行号，可溯源到 Hermes v0.9.0 源码
- **Mermaid 图**用于展示调用链路、类关系、数据流
- **Python 技巧**对装饰器、元类、`__slots__` 等做专门解释

## 推荐阅读路线

根据你的目标，选择最适合的路线：

### ⚡ 入门路线（7 篇）

> 适合：快速建立全局认知，了解 Hermes 是什么、怎么运行

```
01-项目全景 → 02-启动链路 → 05-对话循环 → 11-工具注册表设计
→ 16-子智能体委托 → 17-记忆系统 → 25-架构模式总结
```

这条路线带你走通 Hermes 的主干：启动 → 对话 → 调用工具 → 委托子 Agent → 记忆持久化，最后用设计模式总结串联全局。

### 🤖 AI 工程路线（10 篇）

> 适合：深入 Agent 设计，理解 LLM 应用的工程挑战

```
01-项目全景 → 05-对话循环 → 06-System Prompt 工程 → 07-上下文管理
→ 08-多模型适配 → 09-辅助客户端与成本控制 → 11-工具注册表设计
→ 16-子智能体委托 → 17-记忆系统 → 18-技能系统
```

这条路线聚焦 AI 工程核心问题：如何管理上下文窗口？如何适配多个模型？如何控制成本？如何让 Agent 记住东西？

### 🔧 工具开发路线（8 篇）

> 适合：想为 Hermes 贡献代码的开发者

```
01-项目全景 → 03-配置系统 → 11-工具注册表设计 → 12-终端工具深度剖析
→ 13-文件与代码工具 → 附录 A → 附录 B → 附录 C
```

这条路线从工具注册表的内部机制开始，深入分析几类典型工具的实现，最后通过 3 篇实战附录手把手教你开发新工具、新技能、新平台适配器。

### 📚 完整路线（28 篇）

> 适合：系统学习，按顺序通读

按章节编号 01 → 25 顺序阅读，最后阅读附录 A → B → C。
